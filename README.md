Invoice Management App

A simple yet complete invoice management application built entirely in Python, using Tkinter for the graphical user interface and SQLite for data storage.
The app allows users to create, save, preview, and export invoices to PDF.

Features:
 Add clients with full details (name, email, phone, address, postal code)
 Create invoices with item description, quantity, price, and automatic total calculation
 Automatic calculation of Subtotal, VAT, and Total (with two decimal places)
 Invoice preview in a separate, scrollable window
 Export to PDF using the ReportLab library
 Automatic saving to an SQLite database
 Clean and simple GUI, with centered data and a focus on ease of use.
 
Technologies:
  Python 3
  Tkinter (GUI)
  SQLite (Database)
  ReportLab (PDF Export)
